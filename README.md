# מייצר QR Code לפרטי איש קשר

קוד Python שמייצר QR code שכאשר סורקים אותו עם טלפון (iPhone או Android), הוא מציע להוסיף את פרטי איש הקשר לרשימת הקשרים.

## התקנה

1. התקן את התלויות הנדרשות:
```bash
pip install -r requirements.txt
```

## שימוש

### אפשרות 1: גרסה אינטרקטיבית (מומלצת למתחילים)

הרץ את הקוד האינטרקטיבי והזן את הפרטים שלך:
```bash
python interactive_contact_qr.py
```

### אפשרות 2: שימוש פשוט ומהיר

1. ערוך את הקובץ `simple_contact_qr.py`
2. החלף את הפרטים בשורות 45-47:
   ```python
   name = "השם שלך"  # החלף בשם שלך
   phone = "+972-50-1234567"  # החלף במספר הטלפון שלך
   email = "your.email@example.com"  # החלף באימייל שלך
   ```

3. הרץ את הקוד:
```bash
python simple_contact_qr.py
```

### אפשרות 3: שימוש מתקדם

השתמש בקובץ `contact_qr_generator.py` לאפשרויות מתקדמות יותר כמו:
- הוספת פרטים נוספים (ארגון, אתר, כתובת)
- עיצוב מעוגל של QR code
- התאמת צבעים וגדלים

```bash
python contact_qr_generator.py
```

## איך זה עובד?

1. הקוד יוצר קובץ vCard (תקן עבור פרטי איש קשר)
2. הוא הופך את ה-vCard ל-QR code
3. כאשר סורקים את ה-QR code עם טלפון:
   - iPhone: פותח אפליקציית "אנשי קשר" ומציע להוסיף את הפרטים
   - Android: מציע להוסיף לאנשי קשר או פותח אפליקציה רלוונטית

## קבצים שנוצרים

- `my_contact_qr.png` - QR code עם הפרטים שלך
- `contact_regular.png` - QR code רגיל (מהגרסה המתקדמת)
- `contact_styled.png` - QR code מעוצב (מהגרסה המתקדמת)

## טיפים

- וודא שמספר הטלפון כתוב בפורמט בינלאומי (למשל: +972-50-1234567)
- בדוק את ה-QR code על ידי סריקה עם הטלפון שלך לפני שיתוף
- ניתן להדפיס את ה-QR code על כרטיס ביקור או להציג אותו דיגיטלית

## דרישות מערכת

- Python 3.6+
- ספריות: qrcode, Pillow

## תמיכה

הקוד תומך ב:
- iPhone (iOS 11+)
- Android
- כל אפליקציית סריקת QR code שתומכת ב-vCard
